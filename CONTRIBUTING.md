# Contributing

Start by opening an existing demo and reading its prompt. If something fails, report the exact result, browser, device and steps needed to reproduce the problem.

## Suggest an experiment

Open an experiment proposal with the practical task, intended output, useful interactions and constraints. Explain what a reader could learn by comparing the outputs. Avoid building a score around a preferred result.

Agree and freeze the prompt before generating runs. Use a fresh workspace without sibling results, site code or earlier reviews. See [the run protocol](docs/methodology.md).

## Work on the site

Read [AGENTS.md](AGENTS.md) and [maintenance](docs/maintenance.md). Edit presentation files and generators, then run the checks. Do not improve an original output as part of a site change. A corrected or repeated result is a separately identified artefact.

Keep British English, useful link labels and accessible controls. The site must remain usable without JavaScript. Do not add external runtime assets or a frontend framework.

## Submit changes

Describe the user-visible behaviour, validation performed and any remaining limitations. Preserve published URLs. Do not include private archives, recording masters or local tool caches.
