# Cosmic Gravity: document companion

This text accompanies the eight-page LinkedIn PDF. The screenshots show real default scenes, not scored results. [Open the complete result browser](https://daniel-parke.github.io/model-tests/experiments/cosmic-gravity/).

## Page 1: Same brief. Different universes.

Ten original simulations from Astra and Sol across Light, Medium, High, Extra High and Ultra effort. The cover shows Astra Ultra as an editorial feature, not a measured winner.

## Page 2: The task and its limits

Build an interactive gravity simulation in one HTML file, with glowing particles, subtle expansion and satisfying interaction. Use no external libraries or assets. Compare the initial scene, motion and controls in the actual demos.

These historical runs are not a controlled benchmark. Tool use and working context were not fully recorded. The first four runs used the original brief. Later runs added a short naming paragraph with the model and effort label.
